# 05｜六种路径方法怎样公平比较

X2把六种方法接入同一完整任务环境。比较时先固定地图、输入、观测时序、执行策略和统计口径，再解释各方法改变了哪一层；不把单段最短路长度与全队完成时间混为一个目标。

| 方法 | 本项目中负责的机制 |
|---|---|
| A* | 在当前观测图上用启发式进行精确搜索 |
| Dijkstra | 在同图以零启发式作为独立精确基线 |
| D* Lite | 保留并修复自己的增量搜索状态 |
| 原始D* | 使用自身OPEN、代价变化传播和回指针机制 |
| 扫描＋A* | 先改变任务访问顺序，再由A*连接各段 |
| PSO | 在有限粒子和迭代预算内搜索中间航点路径 |

原始D*的实现有明确的伪代码版本适配，不称为逐字复现或Focussed D*。扫描用于任务点遍历，不是区域全格覆盖；本项目的PSO用于路径搜索，不是PSO任务分配。

**共同案例与保存读数**

八邻接、1USV＋5UUV、20初始任务，t6临时禁行、t11新增2点、t18撤销禁行、t24 U4故障，观察窗120s。规划只接收当前观测图，实际位置和路径可能影响后续事件响应。

| 方法 | 完成任务 | 六艇全窗实际航程／m | 团队完成时间／s |
|---|---:|---:|---:|
| A* | 22/22 | 122.598182196 | 54 |
| Dijkstra | 22/22 | 122.598182196 | 54 |
| D* Lite | 22/22 | 122.598182196 | 53 |
| 原始D* | 22/22 | 122.481068550 | 56 |
| 扫描＋A* | 22/22 | 196.679538967 | 85 |
| PSO | 22/22 | 122.481068550 | 55 |

总航程统计六艇[0,120)全部实际位移，含故障前移动与任务完工后中继。团队时间取最后一个任务完成时刻；相等航程仍可能对应不同到达和服务时序。

**结果能支持到哪里**

D* Lite在本案例完成时间最短，不能推广成所有场景的普遍排名。有效扩展、逻辑弹出和PSO适应度评价是不同工作单位；搜索计时边界也要分别说明。

PSO使用8个中间航点、40粒子、最多60轮和固定局部种子。5个局部种子均找到与参考最短路等长的合法路径，仍不能保证其他查询或场景最优。初始化、解码和失败处理不调用A*修复；独立Dijkstra仅用于核对差距。

完整运行中，未选中分配候选query63存在1.757359313m的局部差距，该数不等于实际多走的航程。有限预算未找到路径也不能直接判定几何不可达；失败和保留前缀的语义需要单独核对。

P6曾从真实远端固定提交与新隔离环境复跑A*／Dijkstra，两组确定性数据与原基线一致。这属于工程复现证据，未增加本人课程运行；后续目录迁移验证单独登记在[复现说明](../../README.md#6运行指南)。
