# 候选研究问题卡｜通信状态滞后下的动态接手

状态：P6交付建议，尚未正式选题、实现或开展新实验。对应导师方向1（水声约束调度），关联方向5（动态重规划）；本卡只研究可控的通信状态滞后代理，不冒称真实声学或分布式系统。

**具体问题：在相同1USV＋5UUV、动态任务和故障场景中，集中式动态接手相对固定归属的完成优势，是否会因状态传输延迟／丢包而减弱？对陈旧状态拒绝下发新接手计划，能否减少无效下发，同时保留零延迟时的完成能力？**

已有依据：P4同场景动态22/22、静态16/22；当前决策直接读取即时真实状态，通信只统计距离阈值，尚未阻碍状态或命令。P4-L1质心通信平均好于同场景失联优先组，不能预设某种中继普遍更优。

| 要素 | 下一轮实验定义 |
|---|---|
| 基线 | 固定归属；现有集中式动态接手。仅改变状态传输条件，保持原服务保护、预算和路线规则。 |
| 待检验改进 | 给状态加生成／接收时间；状态年龄超出事先固定阈值时，拒绝向该艇下发新的接手计划并等待新状态。已确认任务继续执行；不把“拒绝下发”算完成。 |
| 公平条件 | 同地图、起点、任务释放、故障时刻、限速、NEU预算、截止时刻与中继策略；三策略共用每个种子的传输事件序列。零延迟／零丢包首先回归既有确定性结果。 |
| 扰动设计 | 延迟0／3／5秒，丢包0／0.2；有限预注册种子，所有组合保留失败。这里只是离散状态消息代理，传播／MAC／路由和物理声学不在本轮结论范围。 |
| 主要读数 | 截止时完成任务数；按执行时真实状态判定的无效下发次数；拒绝下发次数与状态年龄作为诊断。失败完成时间保持null，功耗仍注明NEU代理。 |
| 可证伪预测 | 零扰动时改进组与现有动态组完成数相同、轨迹一致；在至少一个非零扰动配置中，改进组的成对平均无效下发更少，且成对平均完成数不低于现有动态组。任一条件不成立就不接受“在本测试范围有收益”的预测。若所有基线无效下发本来为0，也不宣称改善。 |
| 必须保留的反例 | 故障发生后长时间无更新或临近截止才收到新状态：拒绝下发可能损失接手机会，完成数下降。必须公开这类失败，不能只展示低时延成功组。 |
| 证据与停止条件 | 同步记录真实／观察状态、消息时间、下发／确认／拒绝、任务归属和实际执行；保存逐种子成对表与不确定性。先完成小场景因果核对和零扰动回归，再运行预定矩阵；证据齐备即报告支持／不支持，不无限增加种子寻找正结果。 |
