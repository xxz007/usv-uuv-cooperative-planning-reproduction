# 完成范围与模型边界

P0～P6、X1、X2的课程与工程主线已经完成。导师原文件还提出六个后续研究方向，当前各有部分基础；课程通过不代表六项科研方法全部实现。导师原文保留在作者本地，本仓库不分发全文。

| 范围 | 已有成果 | 仍需后续研究 |
|---|---|---|
| 二维最小Demo | 1USV＋5UUV、20初始任务、障碍、分配、中继、服务、预算、图与动画 | 更广场景和物理参数验证 |
| 路径与任务分配 | 多种搜索、贪心／枚举／CP-SAT／Pyomo、动态接手 | 距离／能耗／通信中断／优先级的完整联合优化、时间窗与多目标模型 |
| MOOS | 单艇原例及任务发布—NAV—同任务完成反馈闭环 | MOOS内完整多艇USV／UUV协同 |
| VRX | 单WAM-V原例、实收相机与二维同任务对照 | 水下六自由度、多艇跨域集成与实艇 |

质心中继在P4-L1 G3保存执行中存在；P3主动画使用失联优先策略。两种中继的来源分别登记，不能把不同运行拼成一个案例。当前几何通信只评价链路，不强制失联停止或模拟消息延迟。

## 导师六个方向的对应

| 方向 | 已有基础 | 主要缺项 |
|---|---|---|
| 水声约束调度 | 距离通信图、中继、分配与移动预算 | 声传播延迟／丢包、MAC／路由、联合调度目标 |
| 能量与通信保持路径 | 安全搜索、余路线预算和路径对照 | 通信／逆流／物理能耗进入联合路径代价 |
| 智能优化任务分配 | 分配求解与动态接手基础 | GA／NSGA等分配算法及公平验证；现有PSO是路径搜索 |
| 中继辅助协同控制 | 两种中继与单艇平台闭环 | 群体控制律、队形、避碰与通信约束控制 |
| 动态分布式调度 | 集中式事件触发重规划、服务保护、故障接手 | 分布式协商、延迟状态交换、滚动优化或MARL |
| 洋流跨域控制 | 二维时间分段均一流、限速与理想补偿 | 空间流场、水下动力学、鲁棒／MPC及物理功耗 |

当前NEU为系数×实际对地移动距离，驻留等假设见各案例。它不等于电池或推进功率实测。采样坐标包络0次违规，也不等于连续避障或艇间碰撞安全。时间未全完成时为null，不能把截止时刻当成功时间。
